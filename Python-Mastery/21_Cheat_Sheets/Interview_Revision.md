# Interview Revision Cheat Sheet\n\n## Common Python Interview Questions\n\n### 1. How do you reverse a string?\n```python\ns = \"hello\"\nreversed_s = s[::-1]\n```\n\n### 2. How do you check if two strings are anagrams?\n```python\ndef are_anagrams(s1, s2):\n    return sorted(s1) == sorted(s2)\n```\n\n### 3. How do you find duplicate elements in a list?\n```python\ndef find_duplicates(lst):\n    return list(set([x for x in lst if lst.count(x) > 1]))\n\n# Better approach using Counter\nfrom collections import Counter\ndef find_duplicates(lst):\n    return [k for k, v in Counter(lst).items() if v > 1]\n```\n\n### 4. How do you find the missing number in a range?\n```python\ndef find_missing(numbers):\n    n = len(numbers) + 1\n    return (n * (n + 1) // 2) - sum(numbers)\n```\n\n### 5. How do you implement FizzBuzz?\n```python\ndef fizzbuzz(n):\n    for i in range(1, n + 1):\n        if i % 15 == 0:\n            print(\"FizzBuzz\")\n        elif i % 3 == 0:\n            print(\"Fizz\")\n        elif i % 5 == 0:\n            print(\"Buzz\")\n        else:\n            print(i)\n```\n\n### 6. What's the difference between == and is?\n```python\n# == checks value equality\na = [1, 2, 3]\nb = [1, 2, 3]\nprint(a == b)  # True\nprint(a is b)  # False\n\n# is checks identity (same object)\nc = a\nprint(a is c)  # True\n```\n\n### 7. What are decorators?\n```python\ndef my_decorator(func):\n    def wrapper(*args, **kwargs):\n        print(\"Before\")\n        result = func(*args, **kwargs)\n        print(\"After\")\n        return result\n    return wrapper\n\n@my_decorator\ndef greet():\n    print(\"Hello\")\n```\n\n### 8. Explain generators\n```python\ndef count_up_to(n):\n    i = 0\n    while i < n:\n        yield i\n        i += 1\n\nfor num in count_up_to(5):\n    print(num)\n```\n\n### 9. What is the LEGB rule?\n- Local: Inside current function\n- Enclosing: Inside enclosing function\n- Global: Module level\n- Built-in: Built-in namespace\n\n### 10. Explain list vs tuple vs set\n```python\nlist = [1, 2, 3]      # Mutable, ordered, duplicates allowed\ntuple = (1, 2, 3)     # Immutable, ordered, duplicates allowed\nset = {1, 2, 3}       # Mutable, unordered, no duplicates\n```\n\n## Data Structure Complexities\n\n| Operation | List | Tuple | Set | Dict |\n|-----------|------|-------|-----|------|\n| Access | O(1) | O(1) | - | O(1) |\n| Insert | O(n) | - | O(1) | O(1) |\n| Delete | O(n) | - | O(1) | O(1) |\n| Search | O(n) | O(n) | O(1) | O(1) |\n\n## Common Algorithms\n\n### Bubble Sort\n```python\ndef bubble_sort(arr):\n    for i in range(len(arr)):\n        for j in range(len(arr) - 1 - i):\n            if arr[j] > arr[j + 1]:\n                arr[j], arr[j + 1] = arr[j + 1], arr[j]\n    return arr\n```\n\n### Binary Search\n```python\ndef binary_search(arr, target):\n    left, right = 0, len(arr) - 1\n    while left <= right:\n        mid = (left + right) // 2\n        if arr[mid] == target:\n            return mid\n        elif arr[mid] < target:\n            left = mid + 1\n        else:\n            right = mid - 1\n    return -1\n```\n\n### Fibonacci\n```python\ndef fibonacci(n):\n    if n <= 1:\n        return n\n    return fibonacci(n - 1) + fibonacci(n - 2)\n\n# Better with memoization\nfrom functools import lru_cache\n\n@lru_cache(maxsize=None)\ndef fibonacci(n):\n    if n <= 1:\n        return n\n    return fibonacci(n - 1) + fibonacci(n - 2)\n```\n\n## Python Best Practices\n\n1.
