# Pythonic Code Cheat Sheet\n\n## List Comprehensions\n```python\n# Instead of:\nresult = []\nfor i in range(10):\n    if i % 2 == 0:\n        result.append(i ** 2)\n\n# Use:\nresult = [i ** 2 for i in range(10) if i % 2 == 0]\n```\n\n## Dictionary and Set Comprehensions\n```python\n# Dictionary\n{i: i ** 2 for i in range(5)}\n\n# Set\n{i % 2 for i in range(10)}\n```\n\n## Unpacking\n```python\n# Tuple unpacking\na, b, c = (1, 2, 3)\n\n# Extended unpacking\nfirst, *middle, last = [1, 2, 3, 4, 5]\n\n# Dictionary unpacking\n{**dict1, **dict2}\n\n# Function unpacking\nargs = [1, 2, 3]\nfunc(*args)\n\nkwargs = {'a': 1, 'b': 2}\nfunc(**kwargs)\n```\n\n## Enumerate and Zip\n```python\n# Instead of:\nfor i in range(len(items)):\n    print(i, items[i])\n\n# Use:\nfor i, item in enumerate(items):\n    print(i, item)\n\n# Zip multiple sequences\nnames = ['Alice', 'Bob']\nages = [25, 30]\nfor name, age in zip(names, ages):\n    print(f\"{name}: {age}\")\n```\n\n## Context Managers\n```python\n# File handling\nwith open('file.txt') as f:\n    content = f.read()\n# File automatically closed\n\n# Lock handling\nwith lock:\n    # Critical section\n    pass\n# Lock automatically released\n```\n\n## Generator Expressions\n```python\n# Instead of list comprehension for large data:\nresult = [i ** 2 for i in range(1000000)]  # Uses memory\n\n# Use generator:\nresult = (i ** 2 for i in range(1000000))  # Lazy evaluation\nfor item in result:\n    print(item)\n```\n\n## Generators\n```python\ndef generate_numbers(n):\n    for i in range(n):\n        yield i\n\nfor num in generate_numbers(5):\n    print(num)\n```\n\n## Name Conventions\n```python\n# Variables and functions - lowercase_with_underscores\nmy_var = 10\ndef my_function():\n    pass\n\n# Constants - UPPERCASE_WITH_UNDERSCORES\nMAX_ATTEMPTS = 3\nPI = 3.14159\n\n# Classes - PascalCase\nclass MyClass:\n    pass\n\n# Private - prefix with underscore\nself._private_var = 10\nself.__very_private = 20  # Name mangling\n```\n\n## Using Truthiness\n```python\n# Instead of:\nif len(my_list) > 0:\n    pass\n\n# Use:\nif my_list:\n    pass\n\n# Instead of:\nif name is not None:\n    pass\n\n# Use:\nif name:\n    pass\n```\n\n## Using .get() with Defaults\n```python\n# Instead of:\nif 'key' in dict:\n    value = dict['key']\nelse:\n    value = 'default'\n\n# Use:\nvalue = dict.get('key', 'default')\n```\n\n## Using Ternary Operator\n```python\n# Instead of:\nif condition:\n    value = 'yes'\nelse:\n    value = 'no'\n\n# Use:\nvalue = 'yes' if condition else 'no'\n```\n\n## String Methods\n```python\n# Instead of building strings manually:\ntext = ''\nfor item in items:\n    text += item + ','\n\n# Use:\ntext = ','.join(items)\n\n# Instead of multiple replaces:\ntext = text.replace('a', 'x').replace('b', 'y')\n\n# Use:\ntext = str.maketrans('ab', 'xy')\ntext.translate(text)\n```\n\n## Using enumerate with start\n```python\n# Start counting from 1\nfor i, item in enumerate(items, start=1):\n    print(f\"{i}. {item}\")\n```\n\n## Using all() and any()\n```python\n# Instead of:\nall_even = True\nfor num in numbers:\n    if num % 2 != 0:\n        all_even = False\n        break\n\n# Use:\nall_even = all(num % 2 == 0 for num in numbers)\n\n# Check if any condition is true\nhas_even = any(num % 2 == 0 for num in numbers)\n```\n\n## Using defaultdict\n```python\nfrom collections import defaultdict\n\n# Instead of:\nif key not in dict:\n    dict[key] = []\ndict[key].append(value)\n\n# Use:\nfrom collections import defaultdict\nd = defaultdict(list)\nd[key].append(value)\n```\n\n## Exception Handling\n```python\n# Instead of:\ntry:\n    result = 1 / 0\nexcept ZeroDivisionError:\n    result = None\n\n# Use:\ntry:\n    result = 1 / 0\nexcept ZeroDivisionError:\n    result = 0  # or handle appropriately\n```\n\n## Main Guard\n```python\nif __name__ == '__main__':\n    # Code that only runs when script is executed directly\n    main()\n```\n"
